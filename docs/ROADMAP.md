## A2 — رابط کاربری (بخش ۱۵ سند مادر)

هدف: کاربر بدون ویرایش کد بتواند کیفیت داده را ببیند، آزمایش اجرا کند و نتیجه/خطا را بفهمد.

| گام | کار | معیار پذیرش |
|---|---|---|
| A2.1 | قرارداد UI + اسکلت سرور محلی (stdlib `http.server`، فقط `127.0.0.1`): `/health`، `/quality`، `/runs` | تست واحد HTTP + اجرای دستی روی localhost |
| A2.2 | فرم اجرا: انتخاب فایل از `data/`، استراتژی، پروفایل هزینه، حالت؛ اجرای پس‌زمینه و وضعیت | اجرای یک آزمایش واقعی از UI + ثبت در artifacts |
| A2.3 | صفحهٔ نتایج: معیارها، جدول معاملات صفحه‌بندی‌شده، موانع/خطاها، لینک manifest | نمایش همان اعدادی که `summary.json` می‌دهد |
| A2.4 | سخت‌سازی: فقط localhost، محدودیت اندازه/مسیر، بدون آپلود بیرونی، پیام خطای صریح | تست امنیتی + بازبینی مستقل |

محدودیت‌ها: بدون وابستگی خارجی، بدون معامله واقعی، بدون سرویس ابری.
